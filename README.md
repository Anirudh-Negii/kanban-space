# Kanban Space

A simple Kanban task management app built with React and Tailwind CSS.

### [Live Demo](https://kanbanspace.vercel.app)

## Features

- Add, edit, and delete tasks
- Move tasks between Todo, In Progress, and Completed
- Search tasks by title
- Filter by priority and status
- Persist tasks in browser LocalStorage
- Responsive user interface

## Getting Started

```bash
git clone https://github.com/Anirudh-Negii/kanban-space.git
cd kanban-space
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Build

```bash
npm run build
```
